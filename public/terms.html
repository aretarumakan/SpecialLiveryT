利用規約・写真の取り扱い

最終更新: 2026-09-13　運営者連絡先: 【連絡先を記入】

「スペマウォッチ」（以下「本サイト」）は、日本の空港にいる機体の状況と、利用者の投稿による特別塗装機の データベースを提供する非商用の個人サイトです。本サイトをご利用の方、とくに塗装情報や写真を投稿される方は、 以下の内容をご確認ください。投稿を行った時点で本規約に同意したものとみなします。

1. 投稿できるもの

  • 写真は投稿者ご自身が撮影したものに限ります。他人が撮影した写真、航空会社やメーカーの公式画像、 SNS や掲示板から転載した画像、生成 AI により作られた画像の投稿は禁止します。
  • 撮影は、撮影場所の管理者が定める規則（空港の撮影ルール、立ち入り禁止区域、私有地の扱いなど）に 従って行われたものである必要があります。
  • 塗装情報（登録記号・塗装名・航空会社・機種・運航期間）は、公式発表など確認できる情報に基づいて 入力してください。出典 URL の入力は必須です。
  • 人物が大きく写っている写真、ナンバープレートなど第三者の情報が判別できる写真は避けてください。

2. 写真の著作権と利用許諾

  • 投稿された写真の著作権は撮影者（投稿者）に残ります。本サイトが著作権を譲り受けることはありません。
  • 投稿者は本サイトの運営者に対し、以下の範囲での非独占・無償・再許諾可能な利用を許諾します。
    • 本サイト上での表示（一覧のサムネイル、塗装ごとの共有ページ、スペマウォッチ画面での表示）
    • 表示のための縮小・切り出し・JPEG への再圧縮（長辺 1600px と 320px の 2 種類を保存します）
    • 共有用 OG 画像（SNS に貼ったときのカード画像）への合成、および SNS 上でのそのカードの表示
    • 本サイトの紹介を目的とした、上記の画面のスクリーンショットの掲示
  • 上記以外の利用（印刷物への掲載、販売、第三者への素材提供など）は行いません。必要が生じた場合は 個別に許諾をお願いします。
  • 許諾は写真が本サイトに掲載されている間に限り有効です。投稿者が写真を削除した時点で終了します （ただし SNS 側のキャッシュや第三者が保存した画像については、運営者が消去できる範囲を超えます）。
  • 本サイトは非商用で運営しており、写真の掲載に対する対価のお支払いはありません。 代わりに、承認された写真は撮影者名付きで代表写真（サムネイル）として表示されます。

3. クレジットの表示

  • 写真は常に撮影者名（表示名）付きで表示します。
  • クレジットに使う名前は投稿した時点の表示名で固定されます。マイページで表示名を変更しても、 すでに投稿された写真のクレジットは変わりません。過去の分もそろえたい場合は運営者にご連絡ください。
  • プロフィールに SNS の URL を登録すると、クレジットからその URL にリンクします（任意）。

4. 削除と修正

  • 投稿者はマイページから、自分が投稿した写真をいつでも削除できます。 削除すると画像ファイルも保存先から消えます。
  • 削除された写真が代表写真だった場合は、次に古い承認済みの写真が自動的に代表写真になります。
  • アカウントごとの削除、登録した塗装情報の修正・削除、クレジット名の一括変更をご希望の場合は、 運営者（【連絡先を記入】）までご連絡ください。
  • 第三者の権利を侵害している、事実と異なるなどのご指摘も同じ窓口で受け付けます。確認のうえ、 必要に応じて非表示・削除します。

5. 塗装情報の扱い

  • 登録記号・塗装名・運航期間などは事実情報として扱い、本サイトで自由に表示・編集・集計します。
  • 投稿された情報は、表記の統一や誤りの修正のため、運営者が編集することがあります。
  • 出典 URL は公式発表（航空会社のプレスリリースなど）を推奨します。リンク先の内容については リンク先の権利者に帰属します。

6. 承認・却下・通報

  • 投稿はいったん「承認待ち」となり、運営者が確認したうえで公開されます。
  • 却下する場合は理由を記載します。理由はマイページで確認でき、直して再投稿できます。
  • 規約に反する投稿、重複、判別できないほど不鮮明な写真などは却下することがあります。
  • 通報が一定数に達した写真は自動的に非公開に戻し、運営者が再確認します。

7. 個人情報

  • ログインは Google などの外部サービスの認証を利用します。本サイトが保持するのは 表示名・SNS の URL・投稿内容と、認証サービスから渡される内部 ID・メールアドレスです。
  • メールアドレスは画面に表示しません。公開されるのは表示名と、登録した場合の SNS の URL だけです。
  • 写真に含まれる撮影日時・位置情報などの Exif は、投稿時の縮小処理で取り除かれます （撮影日・撮影空港は投稿者が入力した分だけを保存・表示します）。
  • 認証とデータの保存には Supabase、配信には Vercel を利用しています。アクセスに伴う通信記録は これらの事業者側にも記録されます。

8. 禁止事項

  • 他人の写真・情報の無断転載、なりすまし、虚偽の投稿
  • 第三者の権利（著作権・肖像権・施設管理権など）を侵害する投稿
  • 本サイトや外部 API に対する過度な自動アクセス、妨害行為
  • 公序良俗に反する内容、宣伝目的の投稿

9. 免責

  • 本サイトの情報（機体の位置・到着予定・塗装情報）は正確性を保証しません。 実際の運航・搭乗に関わる判断には、航空会社や空港の公式情報をご利用ください。
  • 外部 API の停止・仕様変更により、表示が欠けたりサービスを終了する場合があります。
  • 本サイトの利用により生じた損害について、運営者は責任を負いません。

10. 外部データのクレジット

  • 機体の位置情報は adsb.lol の ADS-B データを利用しています。同データは Open Database License (ODbL) 1.0 で提供されています。障害時は adsb.fi を利用します。
  • 便名と出発地・目的地、機体の基本情報は adsbdb を利用しています。
  • 特別塗装機以外の機体写真は Planespotters.net の公開 API を、 同サイトの条件に従い撮影者クレジットとリンク付きで表示しています。各写真の権利は各撮影者および Planespotters.net に帰属します。
  • 特別塗装機の写真は、本サイトの利用者が投稿したもの（クレジット付き）です。

11. 規約の変更

本規約は必要に応じて変更します。重要な変更がある場合は本ページの「最終更新」を改め、トップページ等でお知らせします。 変更後に投稿を行った場合は、変更後の規約に同意したものとみなします。
